# ナビゲーション統合・展開式サイドバー実装計画

トップバーを廃止し、「表示領域の最大化」と「直感的なナビゲーション」を両立するため、画面左端で細く待機し、マウスを合わせた時だけ滑らかに展開する（横幅が広がる）タイプのサイドバーへと刷新します。

## 課題と方針
- トップナビとサイドナビが分かれていると冗長になるため、全てサイドバーに統合します。
- メイン領域（作品の画像など）を今まで以上に画面いっぱいに広く見せるため、通常時のサイドバーの幅を「アイコンだけが見える細い幅（60px程度）」にします。
- アイコンの上にカーソルを乗せると、テキスト（作品名など）を含んだ広い幅（260px）に展開するアニメーションをCSSで実装します。

## Proposed Changes

### 1. `index.html`（構造変更）

#### [MODIFY] index.html
- `<nav class="glass top-nav">` ブロックを完全に削除（廃止）。
- `<aside class="sidebar glass">` 内をアップデート：
  - 上部に「Home」「About」「Contact」へのリンクを持つメインメニュー構造を追加。
  - 下部に「Works」の一覧リンクを配置。
  - 縮小時と展開時の表示を切り分けるため、すべてのリンク内にアイコン（`Feather icons`等の汎用アイコン）＋ テキスト（`<span class="sidebar-text">`）の組み合わせを配置します。例えばそれぞれのWorksには小さな「フォルダアイコン（または丸ポチ）」を付けます。

### 2. `style.css`（アニメーション・レイアウト）

#### [MODIFY] style.css
- `.top-nav` 関連のスタイルを削除。
- `.sidebar` の基本 `width` を `60px` に設定し、`overflow: hidden;` を追加。
- `.sidebar:hover` で `width: 260px;` となるよう指定し、`transition: width 0.3s ease;` のアニメーションを付与。
- `.sidebar-text`（テキスト部分）は通常時 `opacity: 0;`、`.sidebar:hover` 時に `opacity: 1;` となるようフェードインアニメーションを設定します。
- `.main-content` は今まで260pxの余白を持たせていましたが、今後は待機幅である `margin-left: 60px; width: calc(100% - 60px);` に変更。これにより、右側の作品表示領域が最大化されます（サイドバー展開時は上に重なる形で広がります）。

## User Review Required

> [!TIP]
> **アイコンの設定について**
> 縮小状態（60px）の時は、各項目がアイコンのみで表現されることになります。
> - Home, About, Contact には「家・人・手紙」のような標準アイコンを設定します。
> - 各・作品（PreciousHarmony等）の7項目については、区別させやすさを重視して個別のアイコンを探すか、統一感を重視して「全て同じフォルダアイコン、または丸いドット」にするのが一般的です。今回は統一感を出すため「フォルダアイコン」または「ドット（・）」を使用する想定ですが、よろしいでしょうか？

## Verification Plan
1. トップバーが消え、コンタクトやホームリンクがサイドバーに移動しているか。
2. マウスを重ねていない時はサイドバーが細く（テキスト非表示）なり、広大なメインエリアが確保されるか。
3. マウスを左端に乗せるとスッと広がり、隠れていた作品名などの文字が綺麗にフェードインして表示されるか。
