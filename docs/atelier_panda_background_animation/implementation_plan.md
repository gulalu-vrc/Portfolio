# アトリエパンダ 1ページ目背景の動的アニメーション化計画

アトリエパンダのヒーロー画面（1ページ目）の背景を、ショップの代表的な商品画像が上下2段で別方向にゆっくり流れる、リッチなアニメーション背景に変更します。

## ユーザーレビューが必要な事項
- 画像の流れる速度（デフォルトでは非常にゆっくり設定します）。
- 画像の重なり具合や透過度（文字の読みやすさを優先するため、少し暗めに設定する予定です）。

## 変更内容

### [index.html](file:///g:/Git/Portfolio/index.html) [MODIFY]
- `work-atelier-panda` セクションの1枚目 (`work-page-section`) の構造を調整します。
- 背景専用のコンテナ `.panda-marquee-bg` を追加します。
- **上段 (Upper)**: `images/AtelierPanda/` の `1.png`, `2.png`, `3.png`, `4.png` を配置。
- **下段 (Lower)**: `images/AtelierPanda/` の `5.png`, `6.png`, `7.png`, `8.png` を配置。
- シームレスなループを実現するため、画像を繰り返して配置します。

### [style.css](file:///g:/Git/Portfolio/style.css) [MODIFY]
- `.panda-marquee-bg` のスタイリング：
  - セクション全体を覆うように `position: absolute` で配置。
  - `z-index: -1` で背面に。
  - `overflow: hidden` で枠外を見えなくします。
- アニメーションの定義：
  - 上段：右方向へゆっくりスクロール。
  - 下段：左方向へゆっくりスクロール。
- 各画像のサイズ調整 (`object-fit: cover`) と、テキストの読みやすさを確保するためのオーバーレイ設定。

## 検証計画

### 手動確認
- ブラウザで表示し、画像が期待通り上段・下段で別方向に流れているか確認。
- アニメーションが途切れず、シームレスにループしているか確認。
- 前面のテキスト（ショップ名やボタン）の視認性が損なわれていないか確認。
