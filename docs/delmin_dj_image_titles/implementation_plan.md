# デルミンDJセクションの画像内タイトル表示の実装計画

デルミンDJセクション内の画像に対し、内容を説明するタイトル（オーバーレイラベル）を画像内に追加します。これにより、視覚的にどの画像が何を示しているかを分かりやすくします。

## ユーザーレビューが必要な事項
- 各画像に付与するタイトルの文言が適切か確認してください。

## 提案される変更

### [Component] HTML (構造の変更)

#### [MODIFY] [index.html](file:///g:/Git/Portfolio/index.html)
- デルミンDJセクション（`#work-sbr-delmin`）内の各画像を `<div class="zoom-wrapper">` で囲みます。
- 画像の直後に `<div class="image-label">タイトル名</div>` を追加します。

## 検証計画

### 自動テスト
- ブラウザツールを使用して、各画像の下部にラベルが表示されていることを確認します。
- ラベルのスタイル（背景の半透明、ぼかし、文字色）が他のセクションと統一されていることを確認します。

### 手動確認
- レスポンシブ表示（モバイル等）でもラベルが画像内に収まり、レイアウトが崩れていないか確認します。
