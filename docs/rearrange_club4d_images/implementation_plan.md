# 実装計画書: Club4D 解決策カードのレイアウト統一と下揃え調整

Club4D セクションの「実装された解決策」カード 3枚すべてを同じ構成（3枚画像グリッド）に統一し、さらに画像の位置をカードの最下部に揃えるレイアウト調整を行います。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> - 「ハイブリッド制御」の画像構成:
>     - 他の2項目と同様、上段1枚・下段2枚の3枚構成に変更します。
>     - 使用画像: `VRChat_...webp`（上）、`mip.jpg`（左下）、`nikopa.jpg`（右下）
> - 下揃えのレイアウト:
>     - `display: flex` と `flex: 1` を活用し、上の文章が短くても画像が必ずカードの下端に配置されるように調整します。

## 提案される変更点

### 作品紹介コンポーネント

#### [MODIFY] [index.html](file:///g:/Git/Portfolio/index.html)
- **3枚目のカード（ハイブリッド制御）の書き換え**:
    - 画像を3枚使用したグリッドレイアウトを導入。
    - 各画像にキャプション（「実際の演出風景」「実運用 1」「実運用 2」等）を追加。
- **全カードの下揃え対応**:
    - 各 `change-detailed-card` 内の `change-card-content` に `style="flex: 1;"` を追加。
    - これにより、グリッド内のすべてのカードで画像の位置が高さの最大値に合わせて下端に揃います。

## 実施計画

1. `index.html` の Club4D 3枚目のカード構造を修正。
2. 全3枚のカードに `flex: 1` を適用してレイアウトを最適化。
3. デスクトップ表示（横並び）とモバイル表示（スタック）の両方で整合性を確認。

## 検証計画
- 3つのカードすべてが同じ3枚構成になっているか。
- 文章の量が異なっても、画像がすべてカードの最下部に並んでいるか。
- モバイル表示で不自然な余白が発生していないか。
