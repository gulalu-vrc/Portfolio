# 実装計画：オリジナル3Dモデル「クーネル」の追加

ポートフォリオの「Works」セクションに、オリジナル3Dモデル「クーネル」を追加します。
デザインガイドラインに基づき、プレミアムでレスポンシブなグリッドレイアウトを実装します。

## ユーザーレビューが必要な項目

> [!NOTE]
> - 追加位置は、3Dモデル作品としての一貫性を保つため、「SweetWonder」の直後（「Sugar*3」の前）とします。
> - アバター画像の滑らかなスクロール背景（マーキー）は、アトリエパンダやSweetWonderと同じ動的アニメーション背景を採用し、魅力的な第一印象を作ります。

## 提案される変更

### 1. ナビゲーションおよびTOCへの追加

- **サイドバーナビゲーション (Works Menu)**:
  `SweetWonder` のリンクの下に `クーネル` のリンクを追加します。
  - アイコン: `images/icons/BoothIcon.png` (BOOTHアバターのため)
  - リンク先: `#work-kunel`

- **トップページ目次 (TOC - 主な実績)**:
  `SweetWonder` の後に `クーネル` のカードを追加します。
  - サムネイル: `images/Kunel/Photo1@0.5x.png`

### 2. コンテンツセクションの追加

`SweetWonder` セクションの直後に、以下の4ページ構成のセクション `#work-kunel` を追加します。

- **1ページ目：ヒーロー画面**
  - 左側（または右側）のテキストカラム：タイトル「オリジナル3Dモデル「クーネル」」、説明文、個人制作、制作期間のメタデータを表示。
  - 背景：`Photo1@0.5x.png`、`Photo2@0.5x.png`、`Costume.jpg`、`AFK.jpg` を使用した無限ループのマーキーアニメーション。

- **2ページ目：概要・デザイン・モデリング**
  - 左上：**企画概要**（説明文の右側に `Photo1@0.5x.png` を配置）
  - 左下：**デザイン**（説明文の下に `Design1.jpg` と `Design2.jpg` を横並びに配置）
  - 右側：**モデリング**（説明文の下に 2x2 グリッドで `Modeling_Front.png`、`Modeling_Body.png`、`Modeling_Hand.png`、`Modeling_Back.png` を配置）

- **3ページ目：フェイスモデリング・テクスチャ**
  - 左側：**フェイスモデリング**（2x2グリッド。左上に説明文、右上に `Modeling_Face.png`、左下に `TextureFace.png`、右下に `Expression.jpg` を配置）
  - 右側：**テクスチャ**（説明文の下に 2x2 グリッドで `Texture_Vertex.png`、`TextureShadow.png`、`TextureFront.png`、`TextureBack.png` を配置）

- **4ページ目：リギング・完成ギャラリー**
  - 左側：**リギング**（説明文の下に `Bone.png` と `Bone2.png` を横並びで配置）
  - 右側：**完成サムネイル**（`Photo1@0.5x.png`、`Photo2@0.5x.png`、`Costume.jpg`、`AFK.jpg` を2x2グリッドで配置）

## 検証計画

### 手動検証
1. ブラウザを起動し、新しく追加されたサイドバーおよびTOCの「クーネル」のリンクが正しく機能し、セクションに遷移することを確認します。
2. 追加した4ページのレイアウトが崩れず、指定された画像が正しい位置に表示されていることを確認します。
3. すべての画像がクリック可能で、拡大モーダルが正常に動作することを確認します。
4. マーキーアニメーションが滑らかに動作することを確認します。
