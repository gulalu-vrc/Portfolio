# Worksセクションの画像拡大表示機能の拡張計画

Worksセクション内のすべての画像を拡大表示（ズーム）できるようにし、ユーザー体験を向上させます。ヒーロー画像（各作品の冒頭にある背景画像）は拡大対象から除外します。

## ユーザーレビューが必要な事項
- チームメンバーのアイコン（アバター）も拡大対象に含まれますが、これを除外する必要があるか確認してください。現状は「すべての画像」という指示に従い、含める方針です。

## 提案される変更

### [Component] JavaScript (拡大ロジック)

#### [MODIFY] [script.js](file:///g:/Git/Portfolio/script.js)
- `zoomableSelectors` に `.work-project-container img` を追加します。
- これにより、各作品セクション内のすべての `<img>` タグがクリックイベントの対象になります。

### [Component] CSS (スタイル調整)

#### [MODIFY] [style.css](file:///g:/Git/Portfolio/style.css)
- `.work-project-container img` に対し、`cursor: pointer` を設定し、クリック可能であることを示します。
- ホバー時の微小なスケールアップや明るさ調整を追加し、インタラクティブ性を高めます。

## 検証計画

### 自動テスト
- ブラウザツールを使用して、各Worksセクションの画像をクリックし、モーダルが表示されることを確認します。
- ヒーロー画像（背景画像部分）をクリックしても何も起きないことを確認します。

### 手動確認
- スマートフォン表示でも同様に拡大ができるか確認します。
