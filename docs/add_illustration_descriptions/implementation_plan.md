# イラストギャラリーのカスタムレイアウト実装計画

イラストセクションの4枚の画像を、ご指定通りの特殊な配置（左・中央に縦長、右に上下2分割）に変更します。

## ユーザー確認事項
- **表示比率**: 縦長として指定された「ポスター」と「キャラクターサンプル」には、縦長のアスペクト比（3:4等）を強制適用し、トリミングして表示します。
- **レスポンシブ**: 画面幅が狭いモバイル端末では、視認性を確保するため標準的な1カラムまたは2カラムのスタック形式に戻るように調整します。

## 変更内容

### [style.css](file:///g:/Git/Portfolio/style.css)
- `.illustration-gallery-grid` のレイアウトを拡張：
    - デスクトップ表示時に `grid-template-columns: 1fr 1fr 1fr` を適用。
    - `grid-auto-flow: dense` を活用。
- `.gallery-item.portrait` クラスを追加：
    - `grid-row: span 2` を設定し、2行分の高さを確保。
    - 中の `img` に `aspect-ratio: 3 / 4` (または `9 / 12`) を適用。
- 右側のスタックについては、通常のグリッドフローで適切に配置されるように調整します。

### [index.html](file:///g:/Git/Portfolio/index.html)
- ギャラリー内のアイテム順序をご指定の通りに入れ替えます：
    1. 展示用ポスターイラスト案（portraitクラス追加）
    2. キャラクターイラスト・サンプル作品（portraitクラス追加）
    3. 背景コンセプトアート：幻想的な森
    4. 機械仕掛けの空間デザイン
- 各アイテムに適切なクラスと説明文を適用します。

## 検証計画
- PCサイズで 3カラム（縦長2つ、右にスタック2つ）のレイアウトになっているか確認。
- モバイルサイズで崩れずに表示されるか確認。
- 画像が意図した通りにトリミング・配置されているか確認。
