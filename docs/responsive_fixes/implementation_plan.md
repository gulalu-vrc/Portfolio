# レスポンシブデザインの修正計画

ウインドウサイズが小さくなった際のサイドバーの消失問題と、各作品のトップページで文章が切れてしまう問題を修正します。

## ユーザーレビューが必要な事項

- **サイドバーの挙動**: ウインドウ幅が1050px未満の場合、サイドバーを非表示にする代わりに「ハンバーガーメニュー（三本線のアイコン）」を表示し、クリックでサイドバーを展開できるようにします。
- **コンテンツのスクロール**: 1画面に収める（height: 100vh）設定を、コンテンツ量に応じて拡張できる（min-height: 100vh）設定に変更します。これにより、画面が小さい場合に文章を最後まで読めるようになります。

## 提案される変更

### 1. サイドバーのモバイル対応 (Hamburger Menu)

#### [MODIFY] [index.html](file:///g:/Git/Portfolio/index.html)
- `<body>` の直後、または `sidebar` の前に、ハンバーガーメニュー用のボタン `<button id="menu-toggle">` を追加します。

#### [MODIFY] [style.css](file:///g:/Git/Portfolio/style.css)
- `.menu-toggle-btn` のスタイルを追加（通常は非表示、1050px未満で表示）。
- `.sidebar` に `.open` クラスが適用された際のスタイルを追加（画面外からスライドイン）。
- メインコンテンツがサイドバーに被らないよう、または被っても操作できるように z-index を調整します。

#### [MODIFY] [script.js](file:///g:/Git/Portfolio/script.js)
- ハンバーガーメニューのクリックイベントを追加し、サイドバーの開閉を制御します。
- メニューリンクがクリックされた際にサイドバーを自動的に閉じる処理を追加します。

### 2. 文章の切り欠き修正

#### [MODIFY] [style.css](file:///g:/Git/Portfolio/style.css)
- `.work-page-section` と `.work-split-layout` の `height: 100vh` を `min-height: 100vh` に変更します。
- `.work-page-section` の `overflow: hidden` を削除します。
- `.work-text-col` のパディングや配置を調整し、内容が多い場合でもレイアウトが崩れないようにします。

## 検証計画

### 自動テスト（ブラウザツール）
- ブラウザツールを使用して、画面幅を縮小し以下の点を確認します。
  - 1050px未満でサイドバーが隠れ、メニューボタンが表示されること。
  - メニューボタンをクリックするとサイドバーが表示されること。
  - 各作品のトップページで、ウインドウを上下に小さくしても文章が最後まで読める（スクロールできる）こと。

### 手動確認
- 実機（またはブラウザのデベロッパーツール）で、モバイル表示時に操作性に問題がないか確認します。
