# モバイル表示時の横幅オーバーフロー修正計画

モバイル端末（特に画面幅が狭い機種）で確認した際、画面の右側に不要な余白が生じ、横にスクロールできてしまう（横揺れ）問題を修正します。

## 原因分析

1.  **インラインの Grid スタイル**: `index.html` 内に直接記述されている `grid-template-columns: 1fr 1fr;` が、メディアクエリによる CSS の上書き（`1fr`）を阻害し、モバイルでも 2 列表示を維持しようとしています。
2.  **ボタングループの折り返し設定**: 一部のボタンコンテナで `flex-wrap: nowrap;` が指定されており、ボタンが画面幅を超えても改行されずに右側に突き抜けています。
3.  **最小幅の制限**: `.work-text-col` に `min-width: 400px;` が設定されており、375px や 320px のモバイル画面でオーバーフローの原因となっています。

## 提案される変更

### 1. `style.css` の修正

- `.work-text-col` の `min-width: 400px;` をモバイル表示時に解除（または縮小）します。
- `html, body` に念のため `overflow-x: hidden;` を適用し、予期せぬはみ出しを防ぎます（ただし根本原因の解決を優先します）。

### 2. `index.html` のインラインスタイル修正

- **Grid の修正**: `results-container-split` や `work-detail-grid` などに直接書かれている `grid-template-columns: 1fr 1fr;` を削除し、CSS クラス側で制御するように変更します。
- **Flex の修正**: ボタンコンテナの `flex-wrap: nowrap;` を `wrap;` に変更します。
- **ボタンのテキスト**: ボタン内の `white-space: nowrap;` が原因でボタン自体が短くならない場合は、フォントサイズを調整するか改行を許可します。

---

## 検証計画

### 自動テスト（ブラウザツール）
- ブラウザツールを使用して、画面幅を 375px および 320px に設定。
- 横スクロールが発生しないこと（`window.scrollX` が 0 であること）を確認。
- 各作品セクションのボタンやグリッドが 1 列に正しく並んでいることを確認。
