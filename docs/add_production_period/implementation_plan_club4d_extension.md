# 「Club4D」詳細ページ追加計画

「Club4D」の作品紹介を、現在の1枚構成から、商用実績や設計思想を含めた計4枚構成のプロジェクトコンテナーに拡張します。

## ユーザー確認事項
- 実績（Booth価格、販売数、メディア掲載）を強調したレイアウトを採用します。
- 背景画像やギャラリーには、既存の `images/Club4D` 内の画像を適切に配置します。

## 構成案

### 1枚目：ヒーロー画面（現状維持）
- タイトル、概要、背景画像

### 2枚目：商用実績
- **タイトル**: 実運用プロダクトとしての実績
- **内容**:
  - Booth販売実績（7,000円、累計262本）
  - メディア掲載（テレビ朝日「金曜日のメタバース」）
  - アーティストMV出演（MOSAIC.WAV）

### 3枚目：設計思想・こだわり
- **タイトル**: 演出クオリティと運用の両立
- **内容**:
  - **少人数運営への最適化**: 専門知識がなくても直感的に操作できるUI設計。
  - **音楽との完全同期**: BPM連動型シェーダーによる、音と視覚の一体化体験。
- **スローガン**: 「オペレーションコストを下げつつ、演出クオリティを担保」

### 4枚目：技術的ポイント ＆ チーム構成
- **タイトル**: リアルタイム制御を支える技術
- **内容**:
  - **シェーダー**: Amplify Shader Editorによる高速開発。
  - **プログラム**: リアルタイム制御システムの実装。
  - **チーム構成**: プログラム/シェーダー担当としての役割。
