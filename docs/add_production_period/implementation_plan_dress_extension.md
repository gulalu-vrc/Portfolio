# 「イノセント・ガーデンドレス」詳細ページ追加計画

イノセント・ガーデンドレス（黒猫洋品店）の作品紹介を、現在の1枚構成から、詳細な制作プロセスを含めた4枚構成のプロジェクトコンテナーに拡張します。

## ユーザー確認事項
- イラスト画像、完成モデル画像、最終写真についての具体的な指定は、既存の `images/InnocentGardenDress` フォルダ内の画像から適切なものを推測して配置します。

## 構成案

### 1枚目：ヒーロー画面（現状維持）
- タイトル、概要、背景画像

### 2枚目：比較ページ

- **内容**: イラストレーターから提供された原案と、制作した3Dモデルを左右に並べ、再現性の高さを示します。

### 3枚目：フィードバック対応（前編）

- **内容**:
  - **① 形状の再解釈（ビスチェの紐）**: 編み紐の構造的な再設計。
  - **② テクスチャ・質感の強化**: グラデーション、ノーマルマップ、素材感の作り分け。

### 4枚目：フィードバック対応（後編）＆ 完成写真

- **右半分**:
