## ユーザーレビューが必要な項目

> [!IMPORTANT]
> - 画像パス: `images/InnocentGardenDress/LimeIllust.png` および `images/InnocentGardenDress/Lime3D.png` を使用します。
> - レイアウト: 2枚の画像の間に矢印アイコン（Feather Iconsを使用）を追加します。

> - レスポンシブ: スマートフォン表示では画像が縦に並び、矢印は下向き、その下にテキストが表示されるように調整します。
