# 実装計画書: イノセント・ガーデンドレス フィードバック項目の画像追加（3枚化）

フィードバック項目 ①「形状の再解釈」と ②「テクスチャ・質感の強化」の画像をそれぞれ2枚から3枚に増やし、3カラムのグリッドレイアウトに変更します。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> - **使用画像 (①)**: 既存の2枚に加え、`Unity.png` を追加します。
> - **使用画像 (②)**: 既存の2枚に加え、`579ed4b4-d6d3-4e55-ac9a-f599118d7ad8.jpg` を追加します。
> - **レイアウト**: `.spec-image-grid` を 2カラムから 3カラム（`1fr 1fr 1fr`）に変更します。
> - **キャプション**: ユーザーが追加したオーバーレイ形式のキャプション（半透明黒背景、ぼかし）を、追加する画像にも適用します。
