# 実装計画：新規制作物「Sugar*3」の追加

VRChat音楽ユニット「Sugar*3」の活動内容を紹介する新しい制作物ページをポートフォリオに追加します。

## ユーザーレビューが必要な事項
- [ ] 各セクションに配置する画像の内容（AIで生成したプレースホルダー画像を使用します）
- [ ] 実績の「アルバム売上枚数」の具体的な数字（現在は「XXX枚」としておきます）
- [ ] Youtubeリンクの動画ID（現在はプレースホルダーを使用します）

## 予定される変更点

### 1. ナビゲーションおよび目次への追加
- `index.html` のサイドバー (`.works-menu`) に「Sugar*3」へのリンクを追加します。
- `index.html` のヒーローセクション内「主な実績」 (`.works-toc`) に「Sugar*3」のバナーを追加します。

### 2. Sugar*3 セクションの作成
`index.html` の末尾（イラストセクションの前あたり）に、以下の3ページ構成でセクションを追加します。

#### 1ページ目：ヒーロー・イントロダクション
- タイトル：「Sugar*3 - Virtual Music Project」
- 説明文：VRChatを中心に活動した音楽ユニット『Sugar*3』の概要

#### 2ページ目：企画背景・制作意図
- 企画背景：4つのポイント（作品発表の速さ、反応、仲間、市場の空白）
- メンバー紹介：私（作詞作曲編曲、映像）、おとは（ボーカル、作詞）、きょうか（撮影、映像）
- 楽曲制作：ジャンル（Kawaii Future Bass, House等）、ボーカル編集の紹介

#### 3ページ目：制作詳細・実績
- MV制作：VRChat撮影、DaVinci Resolve編集
- ライブ：アバター演出、ペンライトギミック
- 実績：アルバム売上枚数
- Youtubeリンク：動画の埋め込み

### 3. 画像リソースの作成
`images/Sugar3/` ディレクトリを作成し、以下の画像を `generate_image` ツールで生成します。
- `hero.png`: Sugar*3のメインビジュアル
- `standing.png`: メンバーの立ち絵イメージ
- `music_production.png`: 楽曲制作（DAW）イメージ
- `vocal_edit.png`: ボーカル編集イメージ
- `mv_shooting.png`: VRChatでの撮影イメージ
- `video_edit.png`: DaVinci Resolveでの編集イメージ
- `live_avatar.png`: アバター演出イメージ
- `live_penlight.png`: ペンライト演出イメージ

## 確認計画

### 自動テスト / ブラウザ確認
- ブラウザツールを使用して、新しく追加されたセクションのレイアウトを確認します。
- サイドバーからのナビゲーションが正しく動作するか確認します。
- 画像が正しく表示され、クリック時にモーダルが開くか確認します。
- レスポンシブデザイン（モバイル表示）が崩れていないか確認します。

### 手動確認
- ユーザーに生成された画像やテキストの内容、動画リンクのプレースホルダーについて確認を依頼します。
