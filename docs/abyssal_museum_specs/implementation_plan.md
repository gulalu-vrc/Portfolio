# 深海博物館セクション 矢印プロセスの追加計画

## 概要
現在2x2のグリッドで配置されている「反復構造」セクションの画像において、上段の画像から下段の画像へ「変化」を示すための垂直な矢印を左右に2本追加します。

## ユーザーレビューが必要な項目
- レイアウトを現在の `image-grid-2x2` から、2本の垂直カラム（画像→矢印→画像）を並べる形式に変更します。
- 矢印にはプロジェクトのテーマカラー（ピンク/赤系）を使用します。
- **ブラウザを開いてのチェックは行いません。**

## 変更内容

### [index.html](file:///g:/Git/Portfolio/index.html) [MODIFY]
- `image-grid-2x2` の構造を変更し、2つのカラムコンテナを作成します。
- 各カラム内に `feather-icons` の `arrow-down` アイコンを挿入します。

### [style.css](file:///g:/Git/Portfolio/style.css) [MODIFY]
- 矢印付きカラムレイアウト用のクラス `.abyssal-column-flow` とアイコン用のスタイルを追加します。

## 検証計画
- HTMLのネスト構造が正しく、アイコンが適切に配置されているか確認。
- CSSのスタイルが既存のデザイン（ガラスモフィズム等）と調和しているか確認。
