# サイドバーナビゲーション実装計画

画面左側に常に表示され、現在見ている作品をハイライトしつつ、クリックで各作品へジャンプできるメニュー（サイドバー）を実装します。

## 課題と方針

現在、各作品のページは画面幅いっぱいに表示されるよう `width: 100vw` 等で構成されています。
ここにそのままサイドバーを重ねると、左側に配置したサムネイル画像等が隠れてしまう問題が発生します。
そのため、Webページ全体の構造を「サイドバー領域」と「メインコンテンツ領域」に分割し、それぞれが独立して機能する美しいレイアウトに再設計します。

## Proposed Changes

### 1. `index.html`

全体をラップする構造を追加し、左側にサイドバーを配置します。

#### [MODIFY] index.html
- `<body>` 直下に `<div class="app-layout">` などのラッパーを追加。
- 左側の領域として `<aside class="sidebar">` を新設し、7つの作品へのアンカーリンクをリスト化して配置。
  - PreciousHarmony
  - VirtualDiceParty 深海博物館ル・リエー
  - 大手前大学オープンキャンパス
  - Show by rock デルミンDJ
  - クラブアセット Club4D
  - 黒猫洋品店 イノセント・ガーデンドレス
  - keen 靴モデリング
- 既存のすべての `<section>` を `<main class="main-content">` の中に移動。

### 2. `style.css`

サイドバーのスタイリングと、メイン領域のレイアウト調整を行います。

#### [MODIFY] style.css
- `.app-layout`: コンテナとして `display: flex;` を設定。
- `.sidebar`: `width: 260px; height: 100vh; position: fixed; left: 0; top: 0;` のような固定ナビゲーションスタイルを追加。ダークかつグラスモーフィズムなデザイン（半透明の黒など）を採用。
- `.main-content`: `margin-left: 260px; width: calc(100% - 260px);` として、サイドバーに被らないようレイアウトを調整。
- 既存の `100vw` 指定を持つクラス（`.work-page-section` や `.work-split-layout` など）を `width: 100%;` に修正し、はみ出しやスクロールバーの問題を解消。
- サイドバー内のリンクのうち、現在表示されている項目を強調するクラス（`.active`）のスタイルを定義。

### 3. `script.js`

どの作品を現在見ているかを自動判定してハイライトさせる機能（ScrollSpy）を追加します。

#### [MODIFY] script.js
- `IntersectionObserver` を使用し、メイン領域をスクロール中にどの `section`（作品群）が画面の大部分を占めているかを検知。
- 検知したセクションの ID と対応するサイドバーのリンクに `.active` クラスを自動的に付与・付け替えするロジックを実装。

## User Review Required

> [!WARNING]
> **レイアウトの根本的な変更について**
> 全体の左端を250pxほどサイドバーに割り当てるため、これまでの「ブラウザ画面の端から端まで画像が広がるフルスクリーン」という比率から、「右側の残り領域の中で端から端まで広がる」レイアウトに変化します（画面の左端約20%がメニューになるイメージです）。
> サイドバーの幅（太さ）や背景色（半透明の黒、かすかにぼかしを入れる等）についても、ご希望があれば合わせて調整いたします。

## Verification Plan

### Manual Verification
1. 画面左側にサイドバーが表示され、各作品名がリスト表示されているか。
2. リストをクリックした際、該当する作品セクションのトップへ正しくスクロールするか。
3. スクロールに合わせて、サイドバーの文字色や背景が現在見ている作品に切り替わり（自動ハイライト）、現在地が明確に判別できるか。
4. サイドバー追加に伴い、これまでに作成した右側の分割レイアウトなどが崩れていないか。
