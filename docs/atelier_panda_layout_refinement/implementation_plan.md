# アトリエパンダセクションのタイトル整理とリンク追加計画

## 概要
アトリエパンダのプロジェクト詳細（2枚目）において、構成を整理し、ユーザーが直接BOOTH詳細ページへ飛べるようにリンクを追加します。

## ユーザーレビューが必要な項目
- ページ全体のタイトルとして「代表商品」を追加します。
- 各商品のタイトルから「代表商品｜」および「技術開発｜」の文字を削除します。
- 商品名の横に、小さくBOOTHへのリンク（URL）を配置します。

## 変更内容

### [index.html](file:///g:/Git/Portfolio/index.html) [MODIFY]
- アトリエパンダ2枚目セクション（`div.container`内）の冒頭に `<h3 class="detail-page-title">代表商品</h3>` を追加。
- 左カラムのタイトルを「花鳥風月巫女ドレス」に変更し、隣に `https://panda12.booth.pm/items/5389146` へのリンクを追加。
- 右カラムのタイトルを「デスクトップフルトラ」に変更し、隣に `https://panda12.booth.pm/items/4507191` へのリンクを追加。
- リンクは `font-size: 0.8rem` 程度の小さめの文字で実装し、デザインを邪魔しないようにします。

## 検証計画
- タイトルの表示確認。
- リンク先URLの正確性の確認。
- 全体的なレイアウトの整合性確認。
