# 修正内容の確認: PreciousHarmony フィードバック演出への画像追加

PreciousHarmony プロジェクト紹介の「フィードバック設計」セクションにおいて、パーティクルと効果音の解説欄にそれぞれ補足画像を追加しました。

## 実施した変更内容

### 1. 補足画像の配置
- **パーティクル(エフェクト)**: 
    - `images/PreciousHarmony/game_impact.png` を追加しました。
    - クリスタルを叩いた瞬間の鮮やかな視覚効果を確認できます。
- **効果音(SE)**: 
    - `images/PreciousHarmony/006.jpg` を追加しました。
    - ゲームプレイ中の臨場感あるシーンを表示しています。

### 2. レイアウトの調整
- 各 `role-box`（カード形式の枠）の中に画像を収め、テキストのすぐ下に配置しました。
- 画像には以下のスタイルを適用し、他のセクションとの統一感を持たせています。
    - `border-radius: 4px` (マイルドな角丸)
    - `aspect-ratio: 16/9` (標準的な縦横比)
    - `object-fit: cover` (余白を出さないトリミング)
