## ユーザーレビューが必要な項目

> [!IMPORTANT]
> - 画像選定:
>     - パーティクル欄: `images/PreciousHarmony/game_impact.png` （叩いた際のエフェクトが分かりやすい画像）
>     - 効果音欄: `images/PreciousHarmony/006.jpg` （全体のプレイ風景または別の適切なショット）
> - レイアウト: 各 `role-box` 内のテキストの下に、幅いっぱいの角丸画像を配置します。
