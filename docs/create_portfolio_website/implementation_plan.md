# ゲーム業界向け・ポートフォリオサイト実装計画（Vanilla HTML/CSS/JS構成）

## 決定した方針（更新）
*   **技術スタック**: **Vanilla HTML / CSS / JavaScript のみ**。ViteやReactなどのフレームワーク・ビルドツールは一切使用しません。
*   **テーマ**: モダン風（洗練されたダーク/あるいはモノトーンベースのスタイリッシュなデザイン）
*   **構成**: 1ページで完結するシングルページ構成。スクロールに応じて各セクション（Hero, Works, About, Contact）が表示される。

## User Review Required

> [!IMPORTANT]
> Vite(React)からの移行にあたり、以下の構成で再実装を進めます。問題ないかご確認ください。
> 
> **採用技術スタック**
> *   **構造**: ピュアな `index.html`
> *   **スタイリング**: `style.css` (これまでのデザインと同様、グラスモーフィズムやリッチな表現をCSSのみで実装)
> *   **インタラクションとアニメーション**: `script.js` 
>     * スムーズスクロールや、スクロール連動フェードイン表示を「Intersection Observer API」を用いてバニラJSでスクラッチ実装します（Framer Motionの代わり）。
> *   **アイコン**: LucideアイコンのSVGを直接埋め込むか、軽量なアイコンフォント（CDN）を利用します。
> *   **公開時の利点**: ビルドステップ（`npm run build`）が不要になり、ファイル群をそのままVercelやGitHub Pages等にアップロードするだけで即公開可能になります。

## 実装ステップ

### 1. プロジェクトのクリーンアップ
*   現在のVite/React関連ファイル (`package.json`, `node_modules`, `src`, `vite.config.js`) を削除し、ディレクトリをクリーンにします。

### 2. ベース構造の再構築
*   `index.html`ファイルの作成（全セクションを記述）
*   `style.css`ファイルの作成（グローバルスタイル、レイアウト、コンポーネントCSSの移植）
*   `script.js`ファイルの作成（Intersection Observerによるスクロールアニメーション、スムーススクロール）

### 3. スタイリングとアニメーションの移植
*   これまでに実装したモダンデザインのCSSクラスを移植。
*   Vanilla JSによるフェードインアニメーションのクラス付与と調整。
