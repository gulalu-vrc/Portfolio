# ウォークスルー (ポートフォリオサイト・Vanilla移行完了)

Vite(React)の構成をご要望通りに完全に破棄し、「ピュアなHTML / CSS / JavaScript」環境へと移行（再構築）しました。

## 実装内容
1. **不要なツールの排除**
    - `node_modules` や `package.json`、`src` ディレクトリなど、ビルドツールやReactに関連するファイルをすべて削除しました。

2. **構成の再構築**
    - `index.html`: グラスモーフィズムやセクション構成など、Reactコンポーネントで定義していたマークアップをプレーンなHTMLとして書き直しました。
    - `style.css`: Vite/React版で用いていたモダンなスタイル（CSS変数、FlexboxやGridレイアウトなど）を移植し、全く変わらない洗練された見た目を保持しています。
    - `script.js`: `Intersection Observer API` を用いたスクロール連動のフェードインアニメーションや、ナビゲーションをクリックした際のスムーズスクロールをバニラJSで書き直しました。
    - **アイコン**: Lucideアイコンから、CDN経由で読み込める軽量な `Feather Icons` へ置き換えています。

## アセットと公開方法について
ビルドプロセスが存在しなくなったため、**`index.html`, `style.css`, `script.js` をそのままVercelへアップロードするか、GitHubリポジトリ経由で連携するだけで即座にサイトが公開されます**。

手元での動作確認は、特別なコマンド (`npm run dev` 等) を打つ必要すらありません。Windowsのエクスプローラーから `index.html` をダブルクリックしてブラウザで開くだけで、スムーズなアニメーションが確認できます！
