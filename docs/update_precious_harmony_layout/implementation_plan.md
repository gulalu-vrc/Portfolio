# PreciousHarmony「ゲーム内容」レイアウト更新計画

PreciousHarmonyプロジェクトの「ゲーム内容」セクションを更新し、テキストの右側に作品イメージ画像を1枚追加します。これにより、視覚的にゲームの内容がより伝わりやすい構成に変更します。

## 変更内容

### [index.html](file:///g:/Git/Portfolio/index.html)
- `id="work-precious-harmony"` (または該当セクション) の「ゲーム内容」欄を修正：
    - 現在のテキストのみの構成を、`display: flex` または `display: grid` を使用した2カラムレイアウトに変更します。
    - 左側に現在のゲーム解説テキストを配置。
    - 右側に `images/PreciousHarmony/001.jpg` (作品メイン画像) を配置します。
    - モバイル表示時は、画像がテキストの下に回り込むようにレスポンシブ調整を行います。

## 検証計画
- PCサイズで、テキストの右側に画像が正しく表示されているか確認。
- 画像のアスペクト比や角丸（border-radius）が他の箇所と統一されているか確認。
- モバイルサイズで、テキストと画像が縦に正しくスタックされるか確認。
