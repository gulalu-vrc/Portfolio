# デルミンDJセクションのレイアウト調整計画

「ライブハウス構造の最適化（技術詳細）」と「成果」の比率を調整し、成果側を広くします。また、追加された3枚の写真が16:9の比率で美しく表示されるように調整します。

## ユーザーレビューが必要な事項
- 比率調整により、技術詳細側のテキストが窮屈にならないか確認が必要です。
- 16:9の比率を優先するため、グリッド全体の高さが変わる可能性があります。

## 変更内容

### [index.html](file:///g:/Git/Portfolio/index.html) [MODIFY]
- 「技術詳細」側 (`detail-info`) の `flex` 値を `1.5` から `0.7` 前後に縮小します。
- 「成果」側 (`results-cross-grid`) の `flex` 値を `1` から `2.2` 前後に拡大します。
- これにより、画面の約3/4が成果ブロック、1/4が詳細テキストという構成になります。

### [style.css](file:///g:/Git/Portfolio/style.css) [MODIFY]
- `.results-cross-grid` の `min-height` を削除し、アスペクト比に基づいた高さ制御に変更します。
- `.grid-cell` に対し、 `aspect-ratio: 16 / 9` を設定することで、写真が常に16:9で表示されるようにします。
- テキスト枠 (`text-cell`) も同じ比率になるため、コンテンツが収まるようにパディングなどを微調整します。

## 検証計画

### 手動確認
- ブラウザで表示し、成果ブロックが横に長く、写真が16:9 hostの比率になっているか確認。
- 技術詳細側のテキストが読みやすさを維持しているか確認。
- モバイル表示時の切り替え時に違和感がないか確認。
