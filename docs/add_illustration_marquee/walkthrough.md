# イラストレーション・トップページ背景の更新 - Walkthrough

イラストレーションセクションのトップページ背景に、アトリエパンダセクションと同様の「アニメーション付きマーキー背景」を実装しました。

## 変更内容

### 1. 動的背景（マーキー）の実装
- `images/Illustrations` フォルダ内の4枚の作品を2段のマーキー形式で配置しました。
- 上段は右方向へ、下段は左方向へゆっくりとループして流れ、イラスト作品をダイナミックに見せる演出を追加しました。

### 2. レイアウトの調整
- アトリエパンダセクションのデザインに合わせ、従来の固定メイン画像（左カラム）を廃止しました。
- 背景全体を作品が見えるエリアとし、その上に作品解説のテキストが重なる構成に変更しています。
- グラデーションのオーバーレイ（`marquee-overlay`）を重ねることで、背景の動きを活かしつつテキストの可読性を確保しました。

## 確認事項
- [x] イラスト画像が左右にループしてアニメーションしていることを確認
- [x] 背景の明るさが抑えられ、白いテキストがはっきりと読めることを確認
- [x] PC・モバイル両方の表示でレイアウトが維持されていることを確認
